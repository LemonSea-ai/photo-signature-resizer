Two things in one tool

Most people just need to make a photo smaller — that's the default here: your image keeps its original dimensions and only the file size drops (for example 12 MB → 80 KB). Questions

I changed the target size but the result didn't get smaller — why?

The target is a maximum. If your image is already well under it (common for small signatures), there's nothing more to remove, so the file stays the same — the tool tells you when that happens. To make a file genuinely smaller, set a target below its current size.

My iPhone photo won't open.

iPhones save photos as HEIC, which browsers can't read. Convert it to JPG first (on iPhone: Settings → Camera → Formats → “Most Compatible”, or share the photo as JPG), then upload again.

Will it hurt the quality?

Compression is lossy, but the tool keeps the highest quality that still fits your size limit. For small targets, cropping tightly first keeps things sharp.
